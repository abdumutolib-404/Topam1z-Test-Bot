# Music Download Crash Fix - handlers.py

## Issue Location: Line ~1915 in handlers.py

**Problem:** When user taps numbered button to download music from search results,
the bot crashes when sending the MP3 file.

**Root Cause:** Missing error handling + potential timeout issues in act_audio()

---

**Find this code:**
```python
    if data.startswith("mdown|"):
        try: idx = int(data[6:])

```

**Replace with:**
```python
    if data.startswith("mdown|"):
        try: 
            idx = int(data[6:])
        except (ValueError, TypeError): 
            await q.answer("Invalid selection", show_alert=True)
            return
        
        results = _music_results.get(uid)
        if not results or idx >= len(results):
            await q.answer("Session expired. Search again.", show_alert=True)
            return
        
        r = results[idx]
        url = r.get("youtube_url")
        if not url:
            await q.answer("No download link available.", show_alert=True)
            return
        
        # Show status message before starting download
        await q.answer(f"⬇️ Downloading: {r['title'][:30]}")
        
        # Delete the search results message to clean up chat
        try:
            await q.message.delete()
        except:
            pass
        
        # Send status message in chat
        lang = await get_lang(uid)
        status_msg = await q.message.reply_text(
            f"🎵 <b>Downloading:</b> {h(r['title'][:60])}\n"
            f"👤 {h(r.get('artist', 'Unknown')[:40])}\n\n"
            f"⏳ This may take a moment...",
            parse_mode=HTML
        )
        
        # Call act_audio with proper error handling
        try:
            await act_audio(update, ctx, url)
            # Delete status message after successful download
            try:
                await status_msg.delete()
            except:
                pass
        except Exception as e:
            log.error(f"Music download callback error for {url}: {e}")
            try:
                await sedit(status_msg, 
                    f"❌ <b>Download failed</b>\n"
                    f"Song: {h(r['title'][:60])}\n\n"
                    f"Try again or choose a different result.",
                    reply_markup=main_kb(lang))
            except:
                pass
        
        return
```

        # Try to send user-friendly error message

## Fix 3: Add timeout to audio sending (line ~820)

**Find the message.reply_audio call in act_audio:**

**Current:**
```python
        await msg.reply_audio(
            path,
            title=AUDIO_TITLE,
            performer=AUDIO_TITLE,
            duration=int(dur) if dur else None,
            caption=f"🎵 {AUDIO_TITLE}",
            reply_markup=menu_btn(),
        )
```

**Replace with:**
```python
        try:
            await asyncio.wait_for(
                msg.reply_audio(
                    path,
                    title=AUDIO_TITLE,
                    performer=AUDIO_TITLE,
                    duration=int(dur) if dur else None,
                    caption=f"🎵 {AUDIO_TITLE}",
                    reply_markup=menu_btn(),
                    read_timeout=180,
                    write_timeout=180,
                ),
                timeout=240  # 4 minutes max for upload
            )
        except asyncio.TimeoutError:
            raise RuntimeError("Upload timeout - file too large or slow connection")
```

3. **Upload timeout** - Prevents hanging on large file uploads
